# 문장 리듬 시각화 설계

## 목표

실제 타이핑의 속도와 멈춤을 종이 오른쪽 여백의 실시간 잉크 파형으로 보여 준다. Platen의 아날로그 타자기 경험을 보완하되, 입력 내용이나 입력 기록을 저장하지 않는다.

## 범위

- 실제 물리 키보드 입력만 리듬으로 기록한다.
- 자동 타이핑 데모와 램프·글꼴·글자 크기 등 컨트롤 조작은 제외한다.
- 직전 입력과의 시간 간격으로 막대의 길이와 잉크 농도를 결정한다.
- 1초 이상 멈춘 경우에는 옅은 공백과 구분선을 표시한다.
- 리셋하면 파형도 함께 비운다.
- `prefers-reduced-motion` 환경에서는 움직임 없이 결과만 표시한다.

## 구현 방식

### 대안 검토

1. DOM 잉크 파형 스트립 (선택)
   - 작은 막대 요소를 오른쪽 여백 레이어에 추가한다.
   - 단일 `index.html` 구조와 잘 맞고 CSS로 종이·잉크 질감을 표현하기 쉽다.
2. Canvas
   - 부드러운 선을 만들기 쉽지만, 반응형 해상도와 위치 동기화 처리가 더 필요하다.
3. SVG
   - 선명하지만 매 입력마다 패스와 요소를 관리해야 해 이 규모에는 과하다.

### 구성 요소

- `rhythmMarginLayer`: 종이 시트와 같은 위치 변환을 공유하는 시각 전용 레이어
- `recordRhythmInput()`: 실제 키 입력의 시간 간격을 계산하는 함수
- `createRhythmMark()`: 속도 또는 멈춤에 따라 막대·구분선을 생성하는 함수
- `clearRhythmMarks()`: 리셋 때 시각 요소를 제거하는 함수

### 데이터 흐름

1. 실제 키보드 이벤트가 입력 대상으로 허용되는지 판별한다.
2. 현재 시각과 직전 실제 입력 시각의 차이를 계산한다.
3. 1초 이상이면 멈춤 구분선을, 그 외에는 속도에 비례한 잉크 막대를 생성한다.
4. 막대는 현재 커서 줄의 세로 위치와 오른쪽 여백의 가로 위치에 붙인다.
5. `updateScreen()`에서 종이 시트와 동일한 변환을 레이어에도 적용한다.

## 스타일·접근성

- 파형은 장식 정보이므로 보조기기에 숨긴다.
- 마우스·키보드 입력을 막지 않는 `pointer-events: none` 레이어로 둔다.
- 종이 본문을 가리지 않도록 오른쪽 패딩 범위 안에만 배치한다.
- 모션 감소 환경에서는 등장 애니메이션을 끈다.

## 검증 기준

- 실제 타이핑에서 오른쪽 여백에 잉크 막대가 실시간으로 나타난다.
- 빠르게 입력한 막대와 천천히 입력한 막대가 시각적으로 구분된다.
- 1초 이상 멈춘 후 입력하면 구분선이 나타난다.
- 자동 데모, 슬라이더/버튼 조작으로는 파형이 추가되지 않는다.
- 리셋으로 본문과 파형이 함께 초기화된다.
- 기존 한글 조합, 리셋, 자동 타이핑, 램프·글꼴·글자 크기·잉크 효과가 유지된다.
