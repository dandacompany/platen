# 깃털펜 작성 모드 디자인

## 의도

밤 조명 아래 타자를 치는 현재 Platen의 감성은 유지하면서, 사용자가 타자기와 깃털펜 중 하나를 골라 서로 다른 필기 경험을 선택하게 한다.

## 목표

- 작성 도구를 `타자기`와 `깃털펜` 중 선택한다.
- 타자기 모드는 현재 시각·소리·동작을 그대로 유지한다.
- 깃털펜 모드는 입력 위치를 따라가는 실제 깃털펜 형태의 가이드와 볼펜에 가까운 짧은 필기 사운드를 제공한다.
- 한글 조합, 자동 타이핑, 리셋, 글자 수, 램프와 조명 슬라이더는 두 모드에서 공통으로 유지한다.
- 깃털펜 모드에서도 밤 램프와 기존 조명 컨트롤을 유지한다.

## 범위 밖

- 실제 음원 파일이나 외부 라이브러리를 추가하지 않는다.
- 저장·내보내기·새 메모 기능은 이번 변경에 포함하지 않는다.
- 모바일 전용 입력 UI는 추가하지 않는다.

## 동작 결정

- 기본값은 기존 호환성을 위해 `타자기`다.
- 작성 도구 선택은 기존 하단 컨트롤 영역에 배치한다.
- 깃털펜은 현재 조합 중인 글자 또는 커서 위치를 따라간다.
- 일반 입력, 공백, 줄바꿈, 삭제는 깃털펜 모드에서 서로 다른 짧은 합성음을 낸다.
- 자동 타이핑도 현재 입력 경로를 사용하므로 선택한 작성 도구의 시각·청각 효과를 따른다.
- `prefers-reduced-motion`에서는 깃털펜 이동 애니메이션을 줄이되 입력 기능과 소리는 유지한다.

## 구현 제약

- 저장소 규칙에 따라 수정 파일은 `index.html` 한 개를 유지한다.
- 외부 의존성과 빌드 도구를 추가하지 않는다.
- 기존 타자기 모드의 DOM과 동작을 회귀시키지 않는다.
