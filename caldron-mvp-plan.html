운동을 기록하는 일을
대화처럼 쉽게

운동 직후 사진이나 글을 보내면, 러닝·헬스·클라이밍 등 어떤 운동이든 AI가 정리하고 사용자가 확인한 기록을 한 앱에 저장합니다.

어떤 운동이든 한 곳에대화 입력확인 후 저장비교와 코칭
핵심 가설CALDRON AI는 러닝·헬스·클라이밍 등 다양한 운동을 한 앱에 모아 기록하고, AI가 종목별 기록을 비교해 나의 성장을 보여준다.
01 · 문제와 사용자

운동은 했지만,
기록은 자꾸 빠진다

누가

운동을 꾸준히 하려는 사람

러닝·헬스·클라이밍처럼 여러 운동을 하며, 종목별 앱을 오가지 않고 한곳에서 변화를 확인하고 싶은 초보·직장인 사용자입니다.

어떤 상황에서

운동 직후, 손이 바쁠 때

땀을 닦고 이동하거나 다음 일정을 준비하는 순간이라 기록 화면을 오래 조작하기 어렵습니다.

무엇이 불편한지

기록 입력은 번거롭고, 회고는 어렵다

거리·시간·횟수·중량을 일일이 입력해야 하고, 지난 기록과 비교해 좋아졌는지 스스로 계산해야 합니다.

해결할 기회

말하듯 남기고, 저장 전 확인한다

입력 부담은 낮추되, AI가 틀릴 수 있다는 점은 사용자의 확인 단계로 안전하게 보완합니다.

02 · MVP 기능과 하지 않을 것

9주차까지는
세 가지에 집중합니다

핵심 01

입력 → 구조화

사진 또는 글에서 운동명, 날짜, 거리·시간·횟수·중량 등 입력된 값만 정리합니다.

핵심 02

확인 → 저장

사용자가 원문과 구조화 결과를 보고 수정·저장·취소를 선택합니다. 운동 종목은 필수입니다.

핵심 03

비교 → 짧은 코칭

같은 종목의 이전 기록과 비교해 변화 한두 가지와 짧은 코칭을 보여 줍니다.

이번에는 하지 않을 것

실시간 음성 코칭 · 웨어러블 자동 연동 · 전문 운동 처방 · 복잡한 대시보드 · 자동 저장(사용자 확인 없는 저장)

03 · 에이전트와 나의 역할

속도는 에이전트가,
결정과 신뢰는 사람이

Hermes에게 맡길 일

  • HTML 화면과 입력·확인·저장 흐름 구현
  • 구조화 결과와 비교 요약을 보여 주는 UI 작성
  • 테스트 시나리오·검증 체크리스트 만들기
  • Git 기록과 오류 원인 정리

사람이 판단·확인할 일

  • 어떤 정보가 정확히 저장되어야 하는지 결정
  • AI 구조화 결과가 원문과 맞는지 확인
  • 수정·저장·취소의 최종 선택
  • 실제 사용자가 계속 쓸 만한지 평가

04 · 검증 계획

“된다”가 아니라
근거로 확인합니다

1

입력 정확성

실제 운동 문장 10개를 준비해 운동명·수치가 원문과 일치하는지 건별로 대조합니다.

2

저장 안전성

확인 전에는 저장되지 않는지, 수정·취소·필수값 누락이 정상 처리되는지 직접 테스트합니다.

3

비교의 근거

같은 종목의 과거 기록 2개 이상을 넣고 변화 요약의 숫자가 원자료와 맞는지 계산해 확인합니다.

제출 규칙 확인

공용 디자인 시스템(Material Design 3) 기반 · HTML 파일 1개 · 비밀정보와 개인정보 없음 · 브라우저에서 직접 시연 가능
